❓ 常见问题
如何切换模型？ ▼
在上方模型列表中点击想要使用的模型卡片即可切换。切换后会立即生效，无需重启服务。
也可以通过 API 切换：
curl -X POST /api/models/switch -d '{"model_key":"deepseek"}'
各模型有什么区别？选哪个好？ ▼
小米 MiMo：国产性价比之王，中文理解强，推荐日常使用。
DeepSeek：代码和技术文档理解能力突出，程序员首选。
GPT-4o：综合能力最强，但需要海外支付，价格较高。
通义千问：阿里出品，有免费额度，适合入门体验。
Ollama：本地运行，完全免费，数据不出本机，适合隐私敏感场景。
API Key 安全吗？会不会泄露？ ▼
API Key 存储在本地 .env 文件中，不会上传到任何服务器。
项目已将 .env 加入 .gitignore，不会被提交到 Git 仓库。
如果使用 Ollama 本地模型，则完全不需要 API Key。
提示 "无法连接到模型服务" 怎么办？ ▼
1. 点击下方「测试连接」查看具体错误信息
2. 检查 API Key 是否正确填写（注意不要有多余空格）
3. 检查账户余额是否充足
4. 如果是 Ollama，确认已运行 ollama serve
5. 检查网络连接（部分模型需要代理）
如何同时配置多个模型？ ▼
在 .env 中配置多个 API Key 即可。系统支持自动降级：当当前模型不可用时，会自动切换到有 Key 的备用模型。
建议至少配置一个云端模型 + Ollama 本地模型作为兜底。
📝 环境变量配置 (.env 文件)
# ──── 模型 API Key ────

# 小米 MiMo（推荐）
MIMO_API_KEY=sk-xxxxx

# DeepSeek
DEEPSEEK_API_KEY=sk-xxxxx

# OpenAI
OPENAI_API_KEY=sk-xxxxx

# 通义千问
QWEN_API_KEY=sk-xxxxx

# ──── 默认模型 ────
DEFAULT_MODEL=mimo

# ──── Obsidian（可选）────
OBSIDIAN_VAULT_PATH=~/Documents/Obsidian Vault
